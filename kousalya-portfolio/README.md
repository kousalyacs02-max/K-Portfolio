# Run in VS Code (Live Server)
1. Unzip the folder.
2. Open VS Code > File > Open Folder > choose `kousalya-portfolio`.
3. Install the extension "Live Server" (by Ritwick Dey) from the Extensions tab (Ctrl+Shift+X).
4. Right-click `index.html` > "Open with Live Server" (or click "Go Live" at the bottom right).
5. The site opens at http://127.0.0.1:5500 and refreshes whenever you save.

# Publish free
- Netlify: go to app.netlify.com/drop and drag the whole folder in.
- GitHub Pages: upload the files to a repo > Settings > Pages > Deploy from branch `main` / root.
